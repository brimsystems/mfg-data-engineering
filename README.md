# Data Engineering for Manufacturing Operations

End-to-end data engineering process, including data quality audits and error remediation, integrations across disconnected data systems, and automated pipelines. 

Analytics and ML layers built on top, enabling real-time KPI monitoring, deep-dive diagnostics and root cause analyses, and machine learning forecasts embedded into existing systems.  

&nbsp;

## Project Folders

**Defects & Scrap Costs**:
[`defects_scrap/`](defects_scrap/)

Sheet-metal fabrication shop ($31M revenue). Cleans and integrates data source systems (ERP, MES, QMS, Materials, HR) and builds automated data pipeline flow. Analytics diagnostic report details operating conditions that drive elevated defect rates. KPI dashboard provides real-time view of defects and scrap costs.   

&nbsp;

**Job Costing**:
[`job_costing/`](job_costing/)

Precision machining shop ($56M revenue). Cleans ERP records, integrates machine-monitoring sensors, and builds automated data pipeline flow. Job costing and margin analytics embedded into ERP system. Analytics diagnostic report details job margin distributions, job cost overruns vs. estimates, and jobs that lost money.    

&nbsp;

**OEE & Machine Health**:
[`oee_downtime/`](oee_downtime/)

Precision machining shop ($40M revenue). Cleans and integrates data source systems (MES, IIoT sensors, CMMS, ERP, HR) and builds automated data pipeline flow. Machine learning model forecasts upcoming machine breakdowns, embedded into CMMS system. KPI dashboard provides real-time monitoring of OEE and machine health. Analytics diagnostic report details drivers of lost OEE by machine.
