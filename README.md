# Data Engineering for Manufacturing Operations

Projects lay out end-to-end data engineering process: data quality audit and cleaning, integrations across disconnected systems, and automated pipelines. 

Analytics and ML layers built on top, applied to defects and scrap costs, job costing and margin, and OEE and machine health.
